#  資料探勘Transformers文本分析

## 安裝步驟

**本專案以uv管理，雖有提供requirements.txt但建議使用uv。**

1. 複製本專案並進入
    ```bash
    cd DataMiningTransformers
    ```

2. 安裝依賴
    ```bash
    uv sync
    ```
    或者
    ```bash
    pip install -r requirements.txt
    ```
3. 修改`main.py`開頭的模型訓練和超參數調整相關變數
4. 執行
    ```bash
    python main.py
    ```
